# FHCM Launcher

> **Community preview · provided as is.** FHCM Launcher and the standalone FHCM Map Tool are in active development. Expect bugs and changes between releases. Back up your personal save and start in Sandbox.

FHCM is a Windows desktop launcher for compatible custom maps. It manages map ZIP import, display and session options, and save-safe launch. Pacific Coast Highway is the first map being prepared for the community beta. An existing compatible owned game and runtime are required.

[Launcher and Map Tool downloads](https://github.com/fhcustommaps/fhcm-launcher-public-preview/releases) · [Installation](docs/INSTALL.md) · [Build the installer](docs/BUILD.md)

## Preview features

Use Standard for a first Drive. Experimental Tour has known convoy pacing and regroup issues. Standard and Tour use the same PCH ZIP, while traffic and Drivatar settings are independent.
